# guvolu 控制面设计语言

- **文档类别**：长期维护
- **来源**：外部资料 `outsides/SKILL.md`（fintech-terminal-style，原样保全、扫描排除）消化改制而成；冲突处以本文档为准
- **地位**：X 章的视觉实现规范，约束 `web/` 全部界面代码；与 [docs/ui-design.md](ui-design.md) 的信息架构配套

## 1. 气质与心法

密集金融终端：紧凑、等宽承载数据、面板拼装、近零装饰、颜色只表语义、1px 实线分区、高对比、为扫读优化。**颜色是数据不是装饰；边框是结构不是美化；动画是反馈不是氛围。** 判断法：删掉后信息量不变的视觉元素不该存在。

## 2. Token 纪律（最高优先级）

1. 全部颜色、字号、间距、控件高度、圆角、动效时长、z-index 定义于 `web/src/tokens.css` 的 `:root`，组件样式只准引用变量，禁止裸值（裸 hex、裸 px 字号、裸 z-index、裸 rgba）。
2. 新变量先落 tokens 再引用；`var()` 引用未定义变量会静默回退碎版，评审逐一核对。
3. 一个概念一个 token；发现两组件对同一概念取值不同，向 token 收敛。
4. 间距仅一套 `--sp-*`；控件高度仅 `--h-control`（26px）与 `--h-control-sm`（23px）两档，密集表行 `--h-row`（22px）。
5. 语义列宽用 `ch` 单位入 token。

## 3. 配色与字体（对外部规范的改制裁定）

- 背景四层（整体底、面板、抬升面、输入框）同色相近黑蓝灰，分区靠 1px 边框不靠背景跳变；边框两级（默认、焦点）；文字四级。取值照抄外部规范第 1 节。
- 语义色六个加可编辑标识：positive（上涨、通过、新鲜）、negative（下跌）、warning（警告、**陈旧**）、danger（高危、错误）、info（信息）、disabled（禁用）、editable（可编辑，与 warning 同值专用于输入）。**无品牌色，无随手强调色。**
- 半透明数据色一律 `color-mix` 14% 派生，禁止渐变。仅深色一套主题。
- **裁定（2026-08-06，2026-08-10 位置修订）**：外部规范第 3、6 节引用的 `--state-error` 在其 token 表中并无定义（内部不一致），本项目不设该变量，错误语义一律 `--state-danger`；服务状态与时钟偏移常驻全局 header 右上，不另设重复面板；单位在模块 header 元数据声明一次，不逐格标注。
- **字体改制**（2026-08-07 再修订，Noto 最简方案）：CJK 采用开源 Noto——经 `@fontsource/noto-sans-sc` npm 本地打包（OFL 许可入 NOTICES，精确版本，weight 400 与 500），杜绝系统字体差异与中日字形混排；运行时零外链不变。`--font-ui: "Segoe UI", "Noto Sans SC", sans-serif`（去 system-ui：其自带 CJK 绑定会截胡 Noto 造成跨栈混排，2026-08-07 实测修订）；`--font-mono: "Cascadia Mono", Consolas, "Noto Sans SC", monospace`——数字由拉丁等宽承担并保 tabular-nums 对齐；CJK 全角一致宽由 Noto 保证。像素点缀字体不采用。界面零外部链接，第三方归属仅存 NOTICES 文件。
- 全局 `font-variant-numeric: tabular-nums`。等宽适用域：品种、价格、数量、委托号、成交号、run_id、时间戳、状态码、模块代码、header 元数据。
- 字号八档全部具名（title 18 至 formula 9），主力档 `--fs-table: 13px`；字重至多 600。

## 4. guvolu 语义映射（本项目专属裁定）

| 概念 | 视觉裁定 |
|---|---|
| 运行三态（X-02） | 徽章化：查看=focus 描边、模拟运行=warning、实盘=danger；当前态以描边与文字色点亮，非当前态 muted。不再用大横幅色块 |
| 陈旧（X-06） | 模块 header 右槽 fresh/stale 徽章（绿/橙文字色加相对时刻）；细横幅入面板顶部显示错误码；**旧数据保持可见** |
| 无效值 | 一律 em dash `—`，muted 色；禁止 0、空白、N/A 混用 |
| BUY / SELL | positive / negative 只上文字色，不上底色 |
| 服务状态 | OPEN=positive、PREOPEN=warning、MAINTENANCE=danger，徽章形制 |
| 时钟偏移 | 全局 header 右上末槽紧凑形（如 `±0.5s`），muted 不显眼；仅越限转 warning 色，无说明句 |
| 紧急停止（X-03） | rail 底部 danger 项常驻；命令文本等宽展示 |
| amount / available（X-04） | kv 或表格双列，标签走微标签配方，永不合并 |
| 时区 | 全局 header 声明一次「JST」，各时间戳不再逐个后缀（消重复文本） |
| 规则编号引用 | **界面零文档编号**（2026-08-07 裁定，取代先前「页脚编号」裁定）：规则号、文档号、TBD 号一律不入任何界面位置——对使用者是无意义干扰；规则解释与出处只存在于文档 |

## 5. 布局骨架与未来预留

满屏 grid 壳，页面级 `overflow: hidden`，面板各自滚动：顶部命令条（`--h-command-bar` 48px）、左侧模块 rail（52px 等宽短代码）、中部 workspace 面板网格、**底部全局页脚**（`--h-statusbar`，2026-08-10 用户裁定恢复——取代「全局 footer 不存在」与命令条右上双行状态形态）。模块 footer 不存在（面板事实入 header 元数据槽）；中宽改两列，窄宽改单列并由 workspace 自滚动。

**全局页脚两簇文法**：左簇 `运行三态徽章 · 服务状态 · 连接态 · 报警槽`（安全与横切件，全页常驻可视，X-02/X-03 与 ui-design 4.4 报警契约的落位）；右簇 `run_id · 时区「JST」 · 非缺省基准 · 刷新周期 · 时钟偏移`（声明与计数）。页脚永不承载操作（报警槽点击仅跳转）。

**MON 列宽与资产表**（2026-08-11 增设）：最新价摘要与 K 线共用主列，挂单、成交、资产共用较窄的右列，三者宽度严格相同；右列数据表允许自身横滚，不反向压缩价格图。资产总览采用来源分列加同币种合计，列头依次为来源和 `amount / available`；单所视图只保留该所两列。amount 与 available 都为零的行默认收进同一折叠行，展开仅改变可见行，不修改数据请求或来源选择。

**单线分割（2026-08-08 裁定，取代间距分区）**：模块与面板之间零间距、零圆角——workspace 网格 `gap: 1px` 且容器背景取 `--border-default`，缝隙即唯一分割线（相邻面板共享一线，杜绝双线叠加）；面板自身无外框无圆角；全部圆角 token 归零（token 位保留，取值 0），界面不存在任何圆角。四区之间维持既有 1px 边框。

**模块 rail 即未来功能的预留位**（本次必须实现）：

| 代码 | 模块 | 状态 |
|---|---|---|
| MON | 监控（本查看版） | 激活：左缘 2px focus 线加 elevated 背景 |
| OPS | 操作面 | 禁用，悬浮提示「阶段 6b」 |
| RPL | 回放 | 禁用，悬浮提示「阶段 8」 |
| RSC | 研究 | 禁用，悬浮提示「阶段 9」 |
| OFL | 订单流 | 独立页面（2026-08-08 增设，热力图交互批次实施）；MON 热力图工具行设进入 chip，构成见 footprint-design 第 6.7 节 |
| CAP | 能力范围 | 底簇独立页面（2026-08-06 增设） |
| SET | 设置 | 底簇独立页面，位于 CAP 与 KILL 之间（2026-08-07 增设） |
| KILL | 紧急停止 | danger 色沉底（margin-top auto 加上边框），点击展开命令说明 |

命令条左侧为 wordmark `guvolu`（mono）、命令输入框视觉件（disabled 态，提示「命令面板 阶段 6b」）与**全局品种选择器**（品种上下文全局唯一，ui-design 4.4 定稿）；右侧回归单行简洁（全局状态两簇迁入底部全局页脚，2026-08-10 裁定）。workspace 网格列宽设最小下限，低于下限重排而非压扁面板。

## 6. 面板解剖与 Label 化（消重复文本的机制）

面板 = 唯一原子容器：header（需要时恒高）+ body（自滚动），无 footer。中文短标题（至多四字）以微标签形制居左；控件紧随标题；facts、来源与新鲜度组成右对齐的 nano mono 元数据槽。空间不足时 facts 先截断，来源与新鲜度保持可见。名称已由页面位置或控件语义唯一表达时，标题文字省略；最新价摘要可省略整个 header。全空表格用 no-pad body。

header 元数据文法（2026-08-10 修订）：右侧单行承载 `品种或范围 · 计数` 与 `数据源 · 新鲜度时刻`；空槽跳过、`·` 分隔、nano mono muted。**标签化位置（微标签、徽章、header 元数据、工具行）只准术语与数值，禁止自然语言描述性句**——解释一律迁往文档，不入界面。

标注只有五种形制，禁止自造第六种：

1. **微标签**：`--fs-badge`、muted、uppercase、0.04em 字距；永远比值弱、比值小。
2. **值标注**：派生数字必带标签；单位以 `--fs-micro` muted 跟在值后不入大字。
3. **kv 对**：label 列宽统一 token，数值右对齐等宽；行式标签值布局一律套 `--w-kv-max`（44ch）最大宽——**值随标签就近，不吸附面板右缘**，宽屏不得把标签与值拉开到难以扫读（2026-08-07 裁定）。
4. **表单字段**：本期仅品种选择器，带标签与 `--h-control-sm` 高度。
5. **状态徽章**：mono `--fs-badge` 描边形制；**去方点**（2026-08-07 裁定），语义只由文字色承担，不设任何指示光点。

重复文本消除清单（对现版的整改指令）：各卡重复的「更新 HH:MM:SS（JST)」整行改为 header 徽章；重复的「（JST）」后缀删除（全局 header 声明一次）；正文里的规则解释句一律删除并迁往文档（界面零文档编号）；能力面板的阶段与阻塞项改徽章列。

## 7. 组件语法（照抄外部规范第 6 节，另加本项目裁定）

密集表格（sticky 表头、数值列右对齐等宽、行悬浮 elevated、宽出容器横滚不挤压）、按钮（描边携带语义文字保持中性、唯 danger 文字同色、无实心大按钮）、徽章（描边形制、无方点）、输入（橙色 2px 左边线唯可编辑控件可用）、指标格（微标签加 mono 大值）、空态错误态（mono 文字块，无插画无骨架屏）。

**Tab 形制**（2026-08-07 增补，照抄外部规范激活态语法）：激活 = 2px `--border-focus` 边线加 elevated 背景，方向随组件——水平 tab 用下边线、竖 rail 用左边线；非激活 muted 文字加透明背景；hover 提亮为 primary 文字加 elevated。禁止实底色 tab、圆角胶囊 tab、第二种激活样式。Tab 仅用于页面内分区（设置页、将来研究页），面板内部不用 tab（用工具行 chip）。

**设置页（SET）**（2026-08-07 增设）：rail 底簇独立页面，承载**显示层偏好**——只影响呈现，不触任何采集、交易、限额参数（后者属 OPS 与配置文件，永不入设置页）。分区以水平 tab 组织：

1. **显示** tab：数值格式项——量与合计的缩写形态（`缩写 k/M` 或 `完整`，二选一）、千分位分组（开/关，仅作用于价格与金额类）；每项为 kv 行加控件，即时生效。
2. **数据** tab：只读陈述区——各面板轮询周期、K 线上游刷新策略、数据源标注含义；kv 形制，无控件。
3. **价格图型**在「显示」tab 以单一下拉选择器切换，并持久化于浏览器本地存储：选项分为「OHLC」（蜡烛、美国线）与「单值」（线、面积、基线）两组。图型切换即时生效，但不出现在 MON 的 K 线模块工具行；足迹为订单流专属图型，保留其既有入口与控制。
4. 设置持久化于浏览器本地存储，键名带版本前缀；不写服务端。固定不可配置项（提示框原文显示、时区 JST、单主题深色）在「显示」tab 底部以 muted kv 陈列，标注「固定」。

设置项的缺省值即设计语言各节裁定值；设置页永不提供违反本语言的选项（如关闭等宽数字、开启循环动画）。

图表引擎裁定（2026-08-06 修订，引擎为 Lightweight Charts）：容器透明背景融入面板；涨跌用 token 语义色（JS 侧经颜色解析器读取 CSS 变量，禁止另写 hex）；无渐变无阴影。

图表细则（2026-08-07 裁定）：

1. **网格仅横线**：`--border-default` 横线保留作价格参照，纵网格关闭——纵向参照由十字线承担，双网格是噪音。
2. **十字线标签全关**：时刻与数值由放大镜提示唯一承担（普通图型贴图顶缘；足迹明细以底边锚定对应蜡烛高点上方；elevated 底加默认描边、mono、kv 形制），横十字线整体关闭；轴上不再出现随动标签，消重复时间。
3. **提示值按规则精度归一**：提示框数值取 API 原始字符串（按时间键查表），按品种规则（tickSize、sizeStep）做小数位归一与千分位分组；不做 k/M 缩写、不做换算、不经浮点。
4. **精度来自品种规则**：价格轴 `precision` 与 `minMove` 由 tickSize 推导（字符串求小数位，不用浮点判断）；数量精度同理由 sizeStep 推导。
5. **唯一常驻指示物**：价格轴最新价标签与虚线价位线保留（功能性）；除此之外禁一切带色指示物、游标光点、发光效果。
6. **布局固定**：滚动容器一律 `scrollbar-gutter: stable`；图表面板的控件收入面板头下的恒高工具行，徽章区设固定最小宽——数据加载与徽章增减不得引起任何面板外框位移。
7. **全局数值变换器**（2026-08-07 裁定）：一切数值显示经 format.ts 单一变换器——价格类千分位分组（分组仅为显示，来源仍是 API 原文字符串）；量与合计类可缩写（k/M，一位小数）；精度一律由品种规则（tickSize、sizeStep）推导；放大镜提示按细则 3 精度归一与分组，不缩写。同一数值语义全应用同一变换，不得逐处各定。
8. **图型切换**（2026-08-11 修订）：价格主图可在蜡烛、美国线、线、面积、基线五型间切换；切换控件位于 SET 的「显示」tab，使用按 OHLC 与单值分组的下拉选择器，K 线模块工具行不重复放置图型控件。各型样式忠实其引擎文档形态但取色一律 token；基线的基准值取当前数据段首根收盘；量窗格与提示框不随图型变化。
9. **满幅无滚裁定**（2026-08-07 裁定）：4K（3840 宽）视口下 MON 全部面板一屏纳入、零页面滚动；网格行高按视口比例分配而非固定像素叠加；仅当视口低于最小基线时才允许整屏滚动。
10. **盘口精度**（2026-08-07 裁定）：OB 价格按 tickSize 精度加千分位，数量按 sizeStep 精度截尾零；合计用缩写形态。
11. **时序空白通则**（2026-08-07 裁定）：一切时间性质数据的空档如实呈现、绝不插值——K 线缺段留空；热力图录制空档列以可辨纹理区别于「零挂量的黑」并图注「空档=未录制」；表格空数据用文字态。空档是事实，不是待修饰的缺陷。
12. **盘口档列滚动**（2026-08-12 修订）：盘口使用普通滚动浏览，不维持跟随态、不自动回中，也不显示回中控件。**中缝为单行**（高 `--h-ob-row`）：中间价居价格列，左右量列承载带内双侧绝对深度；上下档行逐像素复用三列模板。盘口不平衡不再压缩进中缝：它是**面板右缘全高固定轨**，上半 ASK、下半 BID 以中线为锚向上下伸缩，柱高为当前带宽内该侧存量占比；百分比右对齐且不覆盖条形。价差 tick 位于盘口 header，微价格、报价货币价差和覆盖范围进入中线悬浮说明。档位变化使用稳定价位键加短位移动效与一次淡入，不采用整行持续闪烁；位移走 fast 时长，变化底色走 flash 时长，均受 reduced-motion 关闭。
    **现行 MON 盘口形制（2026-08-12）**：不采用成交强度计或档位聚合；工具行仅保留 5/10/25bp 带宽和等档。默认档位行与中缝使用 `--h-ob-row`，三列模板固定为「卖侧深度｜价格｜买侧深度」，深度条在文字下方绘制；ask 数值右对齐、bid 数值左对齐。等档启用后，行高降为 `--h-row`，相邻报价之间按真实 bp 插入空档，空档共同缩放为 0.5 倍；价格列两侧的点划导轨标出空档全高，较大空档直接显示精确 bp，兼顾比例比较与读数；同列小数位恒定，尾部以截尾保齐。
13. **指标行单行完整**（2026-08-11 修订）：最新价六项等宽分列、相邻项以全高 1px 分割线隔开；每项内部标签靠左、数值靠右，以稳定间距建立成对关系。常用桌面宽度下完整显示；极窄窗口优先保留标签并裁切长值，禁止换行或让任何单项撑破主图宽度。
14. **下拉选择器**（2026-08-11 修订）：下拉选择器保留右侧 `▾` 展开指示符，去除 2px 橙色左边线；下拉本身不是自由编辑输入，展开箭头是唯一且明确的操作提示。宽度按内容 ch 定，不设饱和留白。
15. **会话极值线**（2026-08-09 增设，派生层开关）：主图可开会话高低点虚线加轴标签；当前价与极值的距离只入放大镜提示，不上图面文本。
16. **盘口轴投影**（2026-08-09 增设，派生层开关，缺省关）：主图价格轴右缘按当前盘口档位画短刻线——上卖下买语义色、长度=档挂量分位；同轴同域融合，替代「深度带融进价格窗格」的重墨形态（后者不采纳：盘口历史职权在热力图，一处一表）。
17. **数值基准切换**（2026-08-09 裁定，2026-08-10 位置修订）：数量语义可在**数量基准**（基础币原文）与**金额基准**（价乘量的计价币换算）间全局切换——SET 显示 tab 增该项，缺省数量基准；非缺省时全局 header 声明一次（如 `基准 JPY`）。换算走定点整数乘法（BigInt，零浮点）、截尾显示；换算值属派生显示，放大镜提示恒为基础单位原文加规则精度，不随基准变化。足迹格值与深度带的金额基准由服务端逐笔精确累计供给，前端零换算（档价近似换算被禁止）。逐行单位后缀不采纳（单位由模块或全局 header 声明）。
18. **最新价与 K 线编排**（2026-08-11 增设，续修）：MON 的最新价面板仅承载一行紧凑行情且不设标题行；六项各自以紧邻的“标签 数值”同一基线横排，指标按内容取宽，不把数值推到六等分格的远端。最新价固定为一条工具行，K 线从其下沿立即开始并占满左侧余高；资产改入底部浮动停靠栏，不再占用顶端右列。K 线、盘口、热力的工具行由周期、档位或热力控制与元数据辨识，标题文字不重复出现。释放的纵向空间优先分配给 K 线主图与右侧盘口，保证价格观察区始终大于最新价摘要区。
19. **资产来源与账户字段**（2026-08-11 增设）：资产表只承载各交易所 `amount` 与 `available` 的原文十进制字段；总览只对相同币种逐列求和，禁止跨币种、跨法币或跨账户估值。来源缺失、权限不足和读取失败分别作为来源状态显示，单元格写「—」而非零。amount / available 以外的保证金、抵押、未实现盈亏、可取现额等字段不挤入资产表，后续若有需求以独立面板陈列。零余额展开/折叠属于表级显示控制，与来源选择并列放在资产标题工具行；表体不另占一行放控制。
20. **MON 盘口对齐**（2026-08-12 修订）：卖侧数量、价格、买侧数量固定为三列，所有档行与中缝复用同一列模板；默认盘口专用行高为 `--h-ob-row`（`--h-row` 的 1.5 倍），数量文字垂直居中并留同一 micro 级内边距，使色带贴近数值而不压字。累计深度条向外生长并以同一双侧峰值比例缩放，逐档文字仍为该档数量而非累计量；累计背景上另叠 2px 单档量细条，按双侧共同的单档峰值缩放，用于识别局部墙量。中缝与普通档行等高且永不换行：中间价单独居中，价差 tick 不进入中线布局而显示在面板 header；ASK 标签在外、数值在内且右对齐，BID 数值在内且左对齐、标签在外，故中缝数量与相应档位列逐列一致。**盘口不平衡在最右全高固定轨，上 ASK、下 BID，柱分别从中线向外伸缩，百分比贴轨右缘对齐**。工具行使用 chip 样式的「等档」按钮，默认关闭；开启后在相邻报价之间按实际 bp 插入比例空白，同时将行高压到 `--h-row`、空档按 0.5 倍共同缩放。价格列两侧的点划导轨贯穿空档全高，较大空档显示实际缺失的 bp；显示长度保持带宽约束，读数不受截断影响。盘口不自动回中，始终以普通滚动浏览。价格与定精度数量的连续尾零从第二个起降低文字浓度，非零有效位保持主色；横向不足时完整数值按可用宽度压缩并以悬浮恢复原文，不用省略号裁掉数量级。盘口横向不足时缩小两侧深度绘制区，价格列不得漂移；纵向不足时按档高裁切，手动滚动展开完整档列。REST 阶段盘口刷新为 500ms，查询服务同窗单飞缓存；该值是当前 3 req/s 公共总预算内的最高可持续档，不称作交易所未公布的 Public REST 上限。
21. **MON 盘口与浮动停靠栏**（2026-08-11 修订）：盘口占右侧从工作区顶端到底端的连续纵槽；挂单、成交、热力与资产不再占据网格轨道，而是收进主图左下角的浮动停靠栏。停靠栏常驻四个图标按钮，绝不单独占一行或压缩 K 线、盘口高度；**图标贴工作区左、下边缘，展开层同样贴两边缘并恰接盘口分界线**，边线是结构分割而非外留白。点击任一按钮向上浮出对应详细表、热力图或资产表，再点同一按钮折叠。盘口全高时优先显示更多价档，并可追加带内双侧深度、最优报价/价差、微价格偏离与来源时刻等不混淆的存量指标；成交流和历史深度继续分别归属订单流与热力图。盘口窄槽工具行保留 5/10/25bp、等档、来源和新鲜度，隐藏已由全局品种与带宽控件表达的左摘要，控件不得被元数据裁掉；1,000px 以下浮动面板改为全宽，660px 以下内容自身横滚。
22. **面板 header 信息预算**（2026-08-11 增设）：常驻优先级依次为身份、控件、独有异常或覆盖、来源、新鲜度。全局品种不在子面板重复；周期、bp 带宽、时间跨度等已由选中控件表达的值不再写入元数据；根数、行列数、存储键和阶段号等实现信息退出默认 header。挂单与成交只保留各自计数，热力只保留不可从轴直接读取的价区，OFL 只保留缺口。任何因宽度隐藏的信息必须是已在别处表达的重复项；来源、新鲜度与可操作控件不得被裁切。
23. **资产单行表头**（2026-08-11 增设）：资产在浮动停靠栏按图标收起；展开后，资产标题、来源切换、零值折叠、新鲜度与资产表列名共用同一个表头行，不再另占面板标题行。组合首格可按内容增宽，整表保留横向滚动以保证所有列名和值完整；不得用省略号替代交易所名、amount/available 列义或数值。
24. **图表导航与提示锁定**（2026-08-12 裁定）：画布左键拖动只平移时间，纵向手抖不得改变价格尺度；纵向滚轮以指针所在时间缩放，横向滚轮或触控板横滑平移时间。右价格轴拖动只调价格尺度，底时间轴拖动只调 bar 间距，两轴双击分别复位；窗格分隔线可上下调整。单击数据时间锁定提示框，再点同根、点空白或按 Esc 解锁；拖动和滚轮开始即隐藏未锁定提示。单指横滑归图表、单指纵滑归页面、双指捏合缩放。离开最新端才显现「最新」，其回到右端但保留尺度；「适配」常驻并同时适配查询范围与恢复各窗格价格自动尺度。只有原本位于最新端时，新数据才自动跟随。

## 8. 效果与禁止

hover=背景提一层或文字提一级；激活=2px focus 边线加 elevated；焦点=1px focus 细环；动效仅 120ms/80ms 两档，数据变化闪烁 700ms 播一次即停；循环动画一律禁止；`prefers-reduced-motion` 一刀关停。滚动条自绘 8px。阴影不存在。

禁止清单沿用外部规范第 9 节全部条目（渐变、毛玻璃、阴影卡、胶囊按钮、实心大色块、骨架屏、装饰性进度环、营销化文案等）。符号契约：`—` 空值、`·` 元数据分隔、`▸ ▾` 展开、`▲ ▼` 排序、`→` 流程链，一形一义；禁止带圈数字与伪勾选字符。

## 9. 一致性自检（每次前端评审执行）

1. grep 无裸 hex、裸 px 字号、裸 z-index、裸 rgba（tokens.css 定义处与 lwc.ts 颜色解析器除外——图表引擎不识别 color-mix 语法，解析器经画布回读把 token 值转为具体色，属运行时转换而非设计常量，2026-08-06 裁定）。
2. 每个 `var()` 在 tokens.css 有定义。
3. 控件高度只有两档加表行一档。
4. 小标题全部走微标签配方。
5. 2px 左边线颜色语义符合第 4 节表；1px 左边线只用于结构嵌套。
6. 空值全为 `—`；劝告性警示用 warning 不借用 danger。
7. 屏上无重复文本块：同一信息只出现一次，其余位置徽章化或收入 header 元数据。
8. 界面零文档编号：grep 界面代码无规则号、文档号、TBD 号字样（第 4 节裁定）。
