## 2. 三通道打印口径对照（核心发现）

同一撮合事实在三条公开通道的打印方式不同：

| 通道 | 打印口径 | 证据 |
|---|---|---|
| REST `/v1/trades` | **每笔撮合两行**：BUY 行与 SELL 行同时刻同价同量成对 | 单页 100 行中 side 恰 50/50，49/50 个（时刻,价,量）键组双侧成对 |
| WS `trades` 频道 | 同为双侧成对 | 当日录制 2,604 行、1,289 键组、1,261 组成对（97.8%） |
| 官方 K 线 `volume` | **等于双侧行之和** | 7 个 5 分钟窗 WS 行量合计与 K 线量全部恰为 100.0%（含 969 行的活跃窗） |
| 官方归档 | **每笔撮合一行，单侧** | BTC 三个交易日与 ETH 一日共 24,479 行，双侧成对组为 **0** |

同窗三方对照（2026-08-07，UTC，量单位 BTC）：

| 窗 | WS 行数 | WS 行量合计 | K 线量 | WS/K | REST/K |
|---|---|---|---|---|---|
| 12:00 | 32 | 0.14932 | 0.14932 | 100.0% | 100.0% |
| 12:05 | 76 | 0.23766 | 0.23766 | 100.0% | 100.0% |
| 12:10 | 168 | 0.84052 | 0.84052 | 100.0% | 101.9% |
| 12:15 | 64 | 0.34984 | 0.34984 | 100.0% | 100.0% |
| 12:20 | 18 | 0.02412 | 0.02412 | 100.0% | 100.0% |
| 12:25 | 124 | 1.12512 | 1.12512 | 100.0% | 100.0% |
| 12:30 | 969 | 9.53025 | 9.53025 | 100.0% | 100.0% |

REST 唯一偏差窗（101.9%）成因已定位：逐页顺序拉取期间新成交推移分页导致重复行，属采样伪影而非通道差异——**逐页拉取 REST 逐笔必须按（时刻,价,量,侧）去重**。

## 3. 归档是完整记录，不是有损子集

交易日 20260806 全部 286 个有量 5 分钟窗的「K 线量 ÷ 归档量」分布：

| 统计量 | 值 |
|---|---|
| 最小 | 1.000 |
| 中位 | 1.916 |
| 最大 | 2.080 |
| 低于 1 的窗 | **0** |
| 略超 2 的窗 | 27（最大超出 8%，为窗界归属差） |
| K 线有量而归档无量的窗 | **0** |
| 十分位 | 1.15 / 1.37 / 1.59 / 1.78 / 1.92 / 1.98 / 1.99 / 2.00 / 2.00 |

结论链：

1. 比值全体落在 [1, 2]（边界误差内），上十分位钉死在 2.00——与「K 线按双侧计量、归档按撮合单行」完全吻合，与「归档有损」不容。
2. **官方 K 线的 `volume` 不是撮合量**：其值介于撮合量 1 至 2 倍之间（当日全日 1.443 倍，三日分别 1.525 / 1.177 / 1.443），倍率随通道内成对率波动，不是常数。
3. **归档量才是撮合口径的真量**。日对照：20260804 撮合 6,670 笔量 53.7554；20260805 撮合 5,832 笔量 62.2816；20260806 撮合 7,480 笔量 68.1070。
4. 两口径**永不互换**：足迹、Delta、CVD 用撮合口径；K 线量窗格用官方口径；界面与研究不得跨口径比较或求比率。

## 4. 归档 side 为吃单方向（tick 检验）

若归档单行保留的是吃单方（taker）方向，上涨撮合应显著偏 BUY、下跌撮合应显著偏 SELL。三日检验（对照当日 side 基率）：

| 交易日 | BUY 基率 | 上涨撮合 BUY 占比（提升） | 下跌撮合 SELL 占比（提升） |
|---|---|---|---|
| 20260804 | 64.7% | 90.2%（+25.5 点） | 67.9%（+32.6 点） |
| 20260805 | 65.7% | 92.4%（+26.7 点） | 68.4%（+34.1 点） |
| 20260806 | 67.7% | 90.9%（+23.2 点） | 65.7%（+33.4 点） |

双向对基率的提升对称且强——判定 **side = 吃单方向**，Delta 语义成立。ETH 归档同为零成对单侧结构（4,497 行 0 成对），结构跨品种一致。

精确判定尚余一步（见第 7 节探针）：以今日 WS 成对行的**帧内先后次序**联结明日生成的今日归档，确认归档保留侧与行序的对应规则，使实时去重从推断升为确定。
