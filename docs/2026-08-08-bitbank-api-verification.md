## 1. 逐笔端点行为与字段语义

`GET https://public.bitbank.cc/{pair}/transactions/{YYYYMMDD}` 与无日期形态：

| 项 | 实测值 |
|---|---|
| 无日期 | 最新 60 行，降序（新在前） |
| 带日期 | 该 UTC 日全量一次返回，升序，无分页 |
| 字段 | `transaction_id`（整数）、`side`（小写 `buy` 或 `sell`）、`price`（字符串）、`amount`（字符串）、`executed_at`（毫秒整数） |
| 打印口径 | 每笔撮合一行单侧，无双侧成对结构（撮合口径，与 GMO 归档同型） |
| 缺失日 | HTTP 404，`{"success":0,"data":{"code":10000}}`，远古日与未来日同型 |
| 空日 | HTTP 200，`transactions` 为空数组（btc_jpy 20170213 实测） |
| 单日体量 | btc_jpy 近两日 4,322 与 4,596 行（0.47 与 0.50 MB） |

价格与数量为 JSON 字符串、时间戳为毫秒整数：落盘层面原文保存即满足 T-08 与 D-07。

## 3. side 语义：tick 检验

方法同打印口径快照第 4 节（对照当日基率的双向提升）：

| 对与日 | 行数 | buy 基率 | 上涨撮合 buy 占比 | 下跌撮合 sell 占比 |
|---|---|---|---|---|
| btc_jpy 20260806 | 4,322 | 54.6% | 88.8% | 81.6% |
| btc_jpy 20260807 | 4,596 | 60.0% | 90.6% | 79.0% |
| eth_jpy 20260806 | 5,946 | 57.1% | 92.6% | 82.7% |
| eth_jpy 20260807 | 5,891 | 56.1% | 89.4% | 82.8% |
| xrp_jpy 20260806 | 13,383 | 54.0% | 92.5% | 87.9% |
| xrp_jpy 20260807 | 14,941 | 53.2% | 92.2% | 87.2% |

双向对基率的提升对称且强，判定 **side = 吃单方向**。Delta 语义成立，与 GMO 归档口径一致（`trade_tick.aggregated = 0`、`id_origin = venue`）。

## 4. 序号性质：跨对交叠序列与历史变迁

同日三对的 `transaction_id` 区间互相交叠：

| 日 | btc_jpy | eth_jpy | xrp_jpy |
|---|---|---|---|
| 20260806 | 1234643210 至 1234681533 | 1234643255 至 1234681535 | 1234643206 至 1234681519 |

- 对内严格递增、零重复；btc_jpy 20260806 相邻差为 1 的占比 66.1%，最大缺口 424。
- 跨日缺口：btc_jpy 20260806 末 id 与 20260807 首 id 差 8（其间为他对成交）。
- 早期序号逐对自 1 起：btc_jpy 20170214 与 xrp_jpy 20170525 的首笔 `transaction_id` 均为 1（回扫首段归档核实）。序号口径存在历史变迁：早期逐对独立起算，现今跨对区间交叠共用。

判定：现今 `transaction_id` 为跨对交叠的单调序列，早期为逐对独立序列——两种口径都不支持以 id 作单对缺口检测。作 `venue_trade_id` 使用不受影响，唯一性只在来源与品种范围内声明（多源设计第 3 节）；若历史迁移造成同对 id 复用，将在 normalized 重建的主键冲突中检出。

## 9. 对多源设计与采集器的输入

1. venue 登记：bitbank `timestamp_unit = 毫秒`、`trading_day_rule = UTC00`、`write_allowed = 0`。
2. `venue_trade_id` 取 `transaction_id` 文本形态，`id_origin = venue`（第 4 节序号性质不影响此用法）。
3. 逐笔按日全量一次返回、无分页：断点续传以「文件已存在即跳过」实现；缺失日与空日分别以 `missing` 与 `empty` 状态入 `archive_coverage`。
4. 映射登记的 `tick_size` 等由 `spot/pairs` 位数字段换算，属实测派生值，raw_source 指向 `2026-08-08/bitbank/spot_pairs.jsonl:1`。
5. bitFlyer 无品种规则公开端点，其 `instrument_map` 的 `tick_size` 等列留空，品种存在性以 08-07 快照的 markets 响应为据。
6. 回补起点取第 5 节实测值，起点前状态由二分与回验证据支撑，不再逐日回查。
