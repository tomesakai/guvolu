## GMO Coin 私有 API

| 错误码 | 含义 | 处置策略 | 依据 |
|---|---|---|---|
| ERR-5012 | 密钥、IP 或权限不匹配 | 视为配置缺陷或越权调用，停止该路径并告警，不重试 | 实测 2026-08-05 |
| ERR-5010 | 签名无效 | 检查签名串构造与时钟偏移（R-05），不重试 | 实测 2026-08-05 |
| ERR-5106 | 请求参数无效 | 属代码缺陷，修正参数后再发 | 实测 2026-08-05 |
| ERR-5123 | 委托不存在（changeOrder） | 按 T-06 以 READ_ONLY 查询实际状态后决策 | 实测 2026-08-05 |
| ERR-5204 | 请求路径不存在（HTTP 404） | 属代码缺陷，修正路径 | 实测 2026-08-05 |
| ERR-151 | 字面义为服务暂不可用；实测在 cancelOrder 目标委托不存在时返回 | 按 T-06 查询后决策，不得直接判定为服务故障 | 实测 2026-08-05 |
| ERR-846 | 履历查询时间窗超过三十分钟（`Time period has exceeded 30 minutes.`） | 属代码缺陷，窗口收窄到三十分钟内再发 | 实测 2026-08-06 |
| ERR-5003 | 请求频率超限（HTTP 200，status 4；公开端点在 5 请求每秒突发下实测触发） | GET 按指数退避后重试（C-08 范围）；写请求按 T-06 查询后决策，绝不自动重发 | 实测 2026-08-06 |
| ERR-5207 | 请求范围无数据（字面义 Not found）：上市前年份、短周期在 2021-04-15 前、尚未开始的 JST 交易日、date 参数形态与周期不匹配 | 视为无数据而非故障，不重试；回补任务据此确定品种数据边界 | 实测 2026-08-06 |

## 登记规则

新错误码：首次遇到时登记，注明依据（实测日期或官方文档位置）。
含义修订：直接更新本册，提交信息中说明。
源于专项调查的条目：引用对应的时效快照文档。
