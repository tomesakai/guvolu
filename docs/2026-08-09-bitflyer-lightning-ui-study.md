- **文档类别**：时效快照（内容冻结），登记于 [docs/00-rules-registry.md](00-rules-registry.md)

## 1. 版面

左图表、中盘口、右账户与下单、最右歩み値与新闻聊天、底部挂单与履历两表、顶部品种滚动条带。盘口为**对角镜像梯形**：卖侧（数量, 价格）居中轴上方偏左、买侧（价格, 数量）居中轴下方偏右，空出的两个对角象限承载双侧合计（Ask 113.49 / Bid 128.96）；中轴行=锁定图标+分组图标+最終取引価格+スプレッド%。固定 30+30 档，nanoScroller 自绘滚动。

## 2. 刷新动画机制（CSS 实证）

| 机制 | 实现 | 证据 |
|---|---|---|
| 成交强度计（右缘纵条） | 买卖各一条 4px 全高元素，充能=translateY 位移（`matrix(1,0,0,1,0,±406)` 对 408px 高），transition transform 平滑，成交推升后衰减回落 | `.excitement-bar__meter--asks`（绿 rgb(51,215,145) 顶锚）与 `--bids`（橙 rgb(249,147,60) 底锚）、`__push` 类 |
| 行进出动画 | keyframes `anim-in` / `anim-out`（含 pseudo 变体） | 样式表盘点 |
| 闪烁类 | keyframes `pulse`、`strobe` | 同上 |
| 品种条带跑马 | keyframes `tickerline` 循环平移 | 同上 |
| 按钮波纹 | keyframes `click-wave` | 同上 |
| 尾零弱化 | 数量 8 位定长显示，尾部零以 `zeros` 类降不透明度 | 类名与截图一致 |

## 3. 盘口视觉要素

- 行内深度条：`orderbook__bar__fill` 宽度比例填充（观察时近零宽、底色透明——低调形态）。
- 价位时间标记：`_5min-here` 类在对应价位行挂「5分前」红标加虚线刻线（历史成交价位参照）。
- 状态机：`board__container--OPEN`、`_is-NORMAL`、`circuit-break-end`、`auctionsum`（板寄せ合计）——熔断与集合竞价为盘口一等状态。
- 底栏「マーケット: RUNNING ▮▮▮▮」四格负载计；`is-locked` 锁定（停自动回中）；`aggregate-board` 档位聚合模式。
- 配色：卖侧绿、买侧橙红（日本红买惯例，与本项目 BUY=positive 相反）。

## 4. 图表区（LightChart，视觉证据）

- **深度带融合**：价格窗格顶缘倒挂 Ask 深度剪影带、底缘 Bid 深度带（各带随时间演化，标注 Ask Depth 112 / Bid Depth 128），细蓝竖条量叠于底带。
- **轴投影迷你盘口**：价格轴右缘按当前档位画绿（上）红（下）短刻线——盘口投影到价格轴。
- **会话极值标注**：低点处三角加价格文本（10210445）；末价标签旁伴注当前价与该极值的距离（15600）。
- 末价点线横贯全宽加右轴高亮标签；另有绿色点线参照价位加轴标签。
- 叠加物：双均线（土黄短、紫长）、SAR 点列、逐根短虚线标记、右下连接态圆点加实时时钟；工具栏=周期下拉、±缩放、全画面、齿轮指标设置。

## 5. 歩み値与单位表达

- 逐行 `时刻 · 价格 JPY · 数量 BTC`——**单位逐行后缀**；着色按价格方向（`is-up` 绿 / `is-down` 红），与前价持平为白色加粗；数量尾零弱化。
- 下单区：予想金額以 JPY 换算显示；价格报警支持 JPY 绝对值与百分比双模（`alert__price--jpy/--pct`）。
- 空态用线稿插画（注文/取引履歴无数据时）。
